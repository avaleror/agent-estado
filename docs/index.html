Over to you.

Short files, inside the repo, so a teammate, another machine, or another AI can see where the project is and pick up from there.

The handoff travels with git pull. The file is HANDOFF.md. The instructions an AI reads are in English.

The note you send

overto share Ada prints this. Paste it to your coworker.

Over to you, Ada.
Project: lab
Remote: git@github.com:ada/lab.git
Branch: main

Pull the repo, or drop these files in the project root:
- HANDOFF.md
- AGENTS.md
- CLAUDE.md

Goal: Make Friday's demo reproducible on a clean laptop.
Next: Write the network section and try it on a fresh lab.

For your AI:
Read HANDOFF.md, follow AGENTS.md, and update HANDOFF.md before you finish.

Install it once

git clone https://github.com/avaleror/overto.git ~/GitHub/overto
~/GitHub/overto/install.sh

Then, in a project

  • overto init writes the files. Fill in HANDOFF.md and commit them.
  • overto show prints the handoff. overto date sets today.
  • overto share writes the note. The files go with the repo.
